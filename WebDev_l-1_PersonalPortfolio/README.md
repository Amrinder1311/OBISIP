## 📖 About the Project

This portfolio website was developed as part of my **Web Development & Designing Internship at Oasis Infobyte**.

The website provides an overview of my technical skills, projects, education, and professional journey through a clean and responsive user interface.

The main focus of the project was to build a portfolio website from scratch while applying fundamental concepts of **HTML, CSS, JavaScript, responsive design, and UI/UX**.

* Responsive portfolio design
* Clean and modern user interface
* Attractive hero section

* Education section
